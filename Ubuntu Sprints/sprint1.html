1. Consultar les versions disponibles de SMPlayer

Primer de tot, consultarem les versions disponibles del programa SMPlayer mitjançant la comanda apt-cache policy smplayer.

Per fer-ho, accedirem al directori /etc/apt/preferences.d/ i executarem la comanda següent: 

cd /etc/apt/preferences.d
apt-cache policy smplayer

↑ Tornar a l'índex

2. Configurar les preferències d'APT

A continuació, crearem el fitxer smplayer dins del directori /etc/apt/preferences.d/. Aquest fitxer servirà per indicar al gestor de paquets APT que done prioritat a la versió 21.10.0 del programa.

Crearem i editarem el fitxer amb la comanda:

nano smplayer

Dins del fitxer escriurem la configuració següent: 

Package: smplayer
Pin: version 21.10.0*
Pin-Priority: 1001

Una vegada guardat el fitxer, actualitzarem la informació dels paquets amb: 

sudo apt update

↑ Tornar a l'índex

3. Afegir el repositori d'Ubuntu Jammy

Ara crearem un nou fitxer anomenat jammy.list dins del directori /etc/apt/sources.list.d/. Aquest fitxer permetrà afegir el repositori Universe de la distribució Ubuntu Jammy.

Accedirem al directori i crearem el fitxer:

cd /etc/apt/sources.list.d/
sudo nano jammy.list

Dins del fitxer escriurem la línia següent: 

deb http://archive.ubuntu.com/ubuntu jammy universe

Després de guardar el fitxer, tornarem al directori de preferències d'APT: 

cd /etc/apt/preferences.d/

↑ Tornar a l'índex

4. Comprovar la versió candidata

Una vegada configurats els repositoris i les preferències, tornarem a executar la comanda apt-cache policy smplayer.

D'aquesta manera podrem comprovar les versions disponibles i verificar que la versió 21.10.0 és la seleccionada com a candidata per a la instal·lació. 

apt-cache policy smplayer

↑ Tornar a l'índex

5. Instal·lar SMPlayer

Quan hàgem comprovat que la versió desitjada està seleccionada, procedirem a instal·lar el programa SMPlayer mitjançant el gestor de paquets APT. 

sudo apt install smplayer

↑ Tornar a l'índex

6. Comprovar la versió instal·lada

Finalment, executarem SMPlayer per comprovar que s'ha instal·lat correctament.

Per obrir el programa utilitzarem la comanda:

smplayer

Una vegada obert, podrem comprovar que disposem de la versió 21.10.0, tal com havíem configurat anteriorment.

↑ Tornar a l'índex
